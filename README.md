# MApp

Android-клиент сервера **MCore**, версия **0.1.2** (`versionCode=3`). Android 10+; совместим с arm64.

## Контроль скачивания в 0.1.2

Каждая запрашиваемая часть (до 4 МиБ) проверяется по SHA-256, размеру и точному
`Content-Range` до записи в файл. MCore вычисляет SHA-256 тела ответа и передаёт
его в `X-MCore-SHA256` при запросе `X-MCore-Integrity: sha256`.
Непрошедшая проверку часть запрашивается повторно, максимум три попытки;
затем загрузка ставится на паузу, подтверждённая позиция не продвигается.
Сначала обновляется MCore: клиент не принимает части без контрольной суммы.
Ранее сохранённые файлы и уже записанный префикс возобновлённой загрузки
автоматически не перепроверяются.

Проверено: сборка/lint, установка поверх 0.1.1, скачивание тестового видео
через HTTPS с проверкой SHA-256; отклонение изменённых, обрезанных частей,
неверного диапазона и отсутствующей суммы; восстановление повторным запросом
и ограничение числа попыток.
Код Java без нативных библиотек: тот же APK используется в локальном x86_64-эмуляторе.
Иконка — собственная векторная кинокамера.

## Сборка на Debian

Репозиторий: `/home/kot/MApp`. JDK 21, Android SDK 35.

```sh
export ANDROID_HOME="$HOME/.local/android-sdk"
./gradlew assembleRelease lintRelease
```

APK: `app/build/outputs/apk/release/app-release.apk`.
Gradle wrapper закреплён на 8.11.1 с SHA-256 дистрибутива.

Ключ подписи и пароль находятся **вне репозитория**:
`~/.config/mapp/release.p12`, `~/.config/mapp/signing.properties` (права 0600).
Для новой установки среды их создаёт `python3 tools/create-signing.py`.
Не заменять существующий ключ при обновлениях: Android требует одинаковую подпись.
Другой путь к свойствам можно передать через `MAPP_SIGNING_PROPERTIES`.
Без файла подписи release APK будет неподписанным.

## Вход

На MCore администратор выполняет `mcore-admin invite <login>` и передаёт полученную
ссылку пользователю. Открыть ссылку в MApp либо вставить её на экране входа.
Срок — две минуты; повторное погашение невозможно. Адрес сервера и отпечаток
сертификата берутся из ссылки. Ключ доступа хранится с AES-GCM в Android Keystore.
Проверка сертификата и имени сервера не отключается.

История восстанавливается по серверному аккаунту, не по аппаратному идентификатору.
Android ID используется только как метка; Android не гарантирует его неизменность
«до перепрошивки».

## Интерфейс

Версия 0.1.1: светлая тема с тёмным текстом, скруглённые кнопки с эффектом нажатия.
Превью уменьшены на 20%: ширина горизонтальной карточки 150 → 120 dp,
высота изображения 110 → 88 dp; постеры в списках 54×76 → 43×61 dp.
Вверху настроек, в разделе «Сервер», добавлена кнопка **«Выйти из аккаунта»**.
Выход удаляет локальное подключение и доступ к старым потокам, останавливает
загрузки и возвращает экран приглашения. История на сервере, файлы и библиотека
на телефоне сохраняются. Новый вход выполняется по свежей ссылке-приглашению.

- Главная: горизонтальная история, поиск с последними запросами, горизонтальный список сохранённого.
- Поиск: подсказки из серверного индекса при вводе; кнопка/Enter запускает поиск по трекерам.
- Карточка: описание, качество/размер/трекер, сиды и пиры цветом, дорожки,
  скриншоты раздачи, просмотр/продолжение и скачивание.
- Несколько файлов: выбор сезона (по имени файла) и серии/файла.
- Сохранённое: незавершённые загрузки сверху, остальные по алфавиту,
  проценты, возобновление, воспроизведение, удаление с подтверждением.
- Настройки: разрешение, буферизация, запрос пути сохранения и папка по умолчанию.
- На главной кнопка «Назад» спрашивает подтверждение выхода.

Все сетевые запросы выполняются только к MCore. Торрент-трекеры, постеры и
скриншоты напрямую с телефона не запрашиваются.

## Внешний плеер

Плееру передаётся `content://` URI с временным разрешением чтения. MApp через
seekable ContentProvider читает диапазоны по pinned HTTPS. Ключ аккаунта плееру
не передаётся, перемотка поддерживается даже с локальным self-signed сертификатом.

Встроенные в контейнер аудиодорожки и субтитры сохраняются. Выбор дорожки выполняется
в плеере: единого Android API для предварительного выбора аудио нет. Настройка
«спрашивать аудиодорожку» пока не реализована; выбор и дополнительные внешние
файлы субтитров требуют отдельных адаптеров конкретных плееров.
Позиция передаётся/принимается через совместимые с VLC/MX Player extras; у других
плееров возврат позиции не гарантируется. Выбранный торрент и файл хранятся в истории MCore.

## Сохранение файлов

Используется системный выбор файла/папки (SAF), либо общая папка `Download/MApp`.
Скачивание работает в foreground service, по HTTP Range, с сохранением прогресса.
После прерывания доступно возобновление из библиотеки.

Готовые файлы остаются после удаления MApp. После переустановки Android отзывает
доступ к документам — нажать «Добавить ранее скачанные файлы» и выдать доступ снова.
Это также работает без подключения к серверу. Для импорта пока используется имя
файла; восстановление локальных постеров/метаданных по sidecar-манифестам не реализовано.

## Проверено локально

Android 15 x86_64-эмулятор на Debian 13, release-подпись:

- Вход через deep link и проверка TLS-сертификата.
- Поиск синтетического `MCore demo`, открытие карточки.
- Передача видео во внешний VLC 3.7.1.
- VLC возвращает позицию: прерывание ролика на 7,4 секунды сохранило `7401` мс
  вместе с выбранным торрентом и индексом файла на MCore.
- Android instrumentation: неправильный TLS pin отклоняется; весь файл через
  ContentProvider совпадает по SHA-256 с HTTPS-ответом, перемотка через границу
  внутреннего буфера возвращает правильные байты.
- Скачивание через системный выбор файла; SHA-256 совпал с исходником MCore.
- Удаление/переустановка приложения: видео осталось, история вернулась после нового входа.
- `assembleRelease` и `lintRelease` проходят; остаются некритичные lint-предупреждения.
- Для 0.1.1 проверена установка поверх 0.1.0, светлый экран настроек, отмена и
  подтверждение выхода, возврат к экрану входа. Android instrumentation проверяет
  удаление ключа и запрет старого stream URI после выхода, сохранение библиотеки,
  а также TLS pin, checksum видео и перемотку.

Пользователь также подтвердил работу предложенных локальных сценариев на телефоне
(установка, вход, просмотр/перемотка, продолжение и скачивание). Модель телефона
и версия Android в этом отчёте не указаны.

Инструменты `tools/emulator-*.py` предназначены только для локального эмулятора.
Приглашение для теста читается из `~/.local/mapp-test.invite` и удаляется после передачи.
Скриншоты тестов и APK — артефакты сборки, не секреты и не часть исходного кода.

После установки APK, входа под тестовой учётной записью и установки локального
demo на MCore Android-проверка запускается так:

```sh
./gradlew assembleReleaseAndroidTest
adb install -r app/build/outputs/apk/androidTest/release/app-release-androidTest.apk
adb shell am instrument -w local.mapp.test/local.mapp.StreamInstrumentation
```

## Ещё требует проверки / доработки

MCore использует только RuTracker и Kinozal через Jackett + FlareSolverr.
Через HTTPS MCore проверен поиск: 62 видеораздачи по запросу «Интерстеллар» от обоих
источников. Получение torrent/magnet проверено; просмотр реального фильма ещё
требует проверки. Выбор источников задаётся сервером, обновление APK не требуется.
Нужны дополнительные проверки разных устройств, внешних плееров и длительных
загрузок. Каталогизация сезонов пока основана на файлах раздачи; это не полноценная
база эпизодов с отдельными описаниями. Полное исходное ТЗ этой сборкой ещё не закрыто.
