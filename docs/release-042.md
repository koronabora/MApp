# MApp 0.4.2 (19)

- Новые загрузки сохраняются в `Название из карточки / Сезон N / файл`.
  Фильм без сезонов — в `Название из карточки / файл`. Название раздачи и
  имя видео не используются как название папки. Папки переиспользуются;
  неизвестный сезон не выдумывается (`Сезон не указан`). Sidecar лежит рядом
  с видео; существующие загрузки продолжаются по своим сохранённым URI.
  Восстановление допускает sidecar до 16 MiB, включая большие карточки сериалов.
- До старта требуются процент файла (по умолчанию 10%) и запас времени
  (по умолчанию 3 минуты, настраивается 1–15 минут). Для потокового просмотра
  проверяется кеш сервера; для сохранённого — проверенные байты на устройстве.
- Временной объём оценивается по длительности/размеру с запасом 25% для VBR.
  Если видео или остаток короче порога, требуется оставшаяся часть целиком.
- Для частично скачанного файла загрузчик сохраняет проверенный хвост
  контейнера (до 8 MiB плюс выравнивание) отдельно в приватном хранилище,
  получает результат разбора контейнера и его длительность. Плеер читает
  хвост локально; обращений к серверу из этого пути воспроизведения нет.
  Без подготовленного хвоста/длительности частичный файл не запускается.
- Полностью скачанные файлы доступны сразу. Старую частичную загрузку можно
  продолжить, чтобы подготовить данные контейнера по новым правилам.
- Политика 0.4.1 (ID вместо больших JSON в Binder) сохранена.
