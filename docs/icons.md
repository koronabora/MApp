# Player icons

Google Material Icons, filled 24dp family, used as Android vectors.
MApp modification: tint references the framework android:attr/colorControlNormal.
The audio-track control uses the volume_up icon.
All player controls use a 30dp glyph area and matching touch targets.

Source: https://github.com/google/material-design-icons
