# MApp 0.3.9 (15)

Карточка продолжает получать готовые источники, пока сервер индексирует раздачи.
Прежний предел в 60 запросов мог оставлять карточку пустой после двух минут,
даже когда сервер позже успешно получил списки серий.

Первые 60 запросов идут с интервалом 2 секунды, дальнейшие — 5 секунд.
Одновременно выполняется не более одного запроса источников на карточку.
После ухода с карточки её цикл обновления останавливается, как и раньше.
