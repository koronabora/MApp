# MApp 0.4.3 → 0.5

- Промежуточная 0.4.3 (20) добавляет автообновление; 0.5 (21) — пользовательский выпуск.
- Постер карточки увеличен с 118×174 dp до 153×226 dp (округление +30%).
- При открытии приложения проверка обновления выполняется не чаще раза в 6 часов;
  ручная проверка доступна в настройках. Ошибки автоматической проверки не мешают просмотру.
- После согласия пользователя APK скачивается через закреплённый TLS-сертификат
  подключённого MCore. Проверяются размер, SHA-256, package ID, versionCode и
  совпадение сертификата подписи с установленным приложением.
- Системному установщику предоставляется доступ только на чтение к одному APK.
  Android запрашивает разрешение установки из MApp и подтверждение обновления.
- Аккаунт, настройки и загрузки сохраняются обычным обновлением поверх приложения.
- API: `/v1/app-update`, `/v1/app-update/{sha256}.apk`, оба требуют авторизацию.
  Серверный каталог `/var/lib/mcore/app-updates`; публикация через
  `tools/publish-mapp.py` атомарно заменяет манифест без перезапуска MCore.

Проверка на Xiaomi 23021RAA2Y прошла: 0.4.3 (20) установлена поверх 0.4.2,
при первом запуске автоматически предложена опубликованная 0.5. APK скачан
самим MApp, после подтверждения разрешения Xiaomi и установки пользователем
ADB подтвердил 0.5 (21), время установки 2026-11-02 16:04:39. Исходное время
первой установки осталось 2026-11-01 17:23:47. Приложение открывается,
аккаунт подключён, история и запись загрузки «Ирландец» (19%) присутствуют.
Ручная проверка в настройках сообщает «Установлена последняя версия: 0.5».

Обе сборки и lint прошли; серверные тесты — 101/101. Gradle-демоны остановлены,
эмуляторы не запускались. Сервер обновлений проверен авторизованным скачиванием
APK с проверкой SHA-256. Прежняя подпись сохранена.
