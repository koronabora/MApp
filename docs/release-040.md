# MApp 0.4 (17)

- В поисковых строках сериалов подпись «Сериал» вместо «Серия / файл».
- Большие карточки и ожидающие выбора папки списки загрузок сохраняются
  атомарно в приватном файле кеша. В системном Bundle остаются только ключ
  снимка, ID карточки и короткие параметры воспроизведения/выбора.
- При пересоздании Activity восстанавливается карточка и выбранный источник.
  Если ОС очистила кеш, карточка повторно запрашивается по её ID.

Причина сбоя на Xiaomi 23021RAA2Y: `TransactionTooLargeException` при остановке
MainActivity после открытия внутреннего или внешнего плеера. В журнале Android
зафиксированы Bundle размером 1 206 840 и 1 552 172 байта; почти весь объём
приходился на JSON карточки. Проверяемый источник: `kinozal:1475843`,
«Игра престолов», 720x400, 42.11 GiB, LostFilm, сезон 1 / серия 1.

Целевой инструментальный тест проверяет подпись, Bundle меньше 64 KiB,
восстановление искусственно увеличенной карточки и реальное воспроизведение.

`assembleRelease`, `assembleReleaseAndroidTest` и `lintRelease` прошли для
первой сборки исправления; финальная 0.4 прошла `assembleRelease`, `lintRelease`
и проверку прежней подписи. SHA-256 APK:
`dfb19ce97be4dfc532a1eb9df0c7672773e4449cdd8daaa64f95092df36d6fe1`.

С разрешения пользователя установлены исправление и тестовый APK, затем
финальная версия 0.4/code 17. Две попытки теста на телефоне завершились
`SocketTimeoutException` при запросе карточки, до проверки плееров; PASS нет.
На сервере тот же HTTPS API отвечал успешно: sources 0,27 с, карточка 2,34 с.
После разблокировки телефона пользователь попросил остановить отладку и
проверить самостоятельно. Повторный тест не запускался. В тестовом сценарии
подготовлен запуск Activity через shell до сетевого запроса; эта правка пока
не проверена на устройстве. Временная настройка удержания экрана включённым
возвращена в 0. Gradle-демоны остановлены, эмуляторы не запускались.
