# MApp 0.3.6

- Скриншоты выбранной раздачи расположены непосредственно под описанием, перед
  селекторами сезона/серии/источника. Информация о раздаче остаётся после источника.
- В «Скачанном» справа отдельные действия: удаление сверху, пауза/продолжение
  ниже с промежутком 32dp. Статус остаётся текстом. Для завершённых файлов кнопка
  управления загрузкой скрывается. Нажатие на карточку открывает просмотр.
- Убрана надпись MApp из панели встроенного плеера.
- История поисковых запросов: жирный заголовок, серые строки с отступом слева;
  предусмотрен светлый серый для тёмного фона.
- Кнопки просмотра, скачивания и скачивания сезона центрированы, их ширина равна
  ширине экрана / φ (примерно 61,8%).
- Заголовок «Кинозал» увеличен с 28sp до 32sp; используется Manrope Bold с кириллицей.
  Шрифт включён в APK, работает офлайн. Источник: google/fonts/ofl/manrope,
  лицензия SIL Open Font License 1.1 включена в assets/licenses/manrope.txt.

Серверная часть MCore 0.3.5 совместима с этим выпуском; изменений API не требуется.

Также исправлена гонка запуска VLC с автоматическим выбором аудио: пауза
устанавливается без проверки переходного состояния и сохраняется при позднем
событии Playing, пока открыт диалог.

Проверки эмулятора: feedback034 (расположение скриншотов, ширина кнопок,
раздельные действия загрузки), navigation и player local:2 с выбором аудио — PASS.
Сборки release/androidTest и lintRelease прошли. Сертификат подписи прежний.
