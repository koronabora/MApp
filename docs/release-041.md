# MApp 0.4.1 (18)

Устранён оставшийся путь `TransactionTooLargeException` при скачивании сезона:
Intent службы содержал запись загрузки вместе с полной карточкой сериала.

Все пять точек запуска/возобновления DownloadService передают только `item_id`:
отдельный файл, очередь сезона/всех сезонов, повторное добавление существующего
файла, действия библиотеки и пауза/возобновление на карточке или в загрузках.
Служба получает актуальную запись из Library после её сохранения. Большие
метаданные остаются в библиотеке и файле восстановления, а не в Binder.

Запуск сохранённого видео во внутреннем плеере также передаёт только ID.
Если запись уже удалена, она не восстанавливается из устаревшего Intent.
Чтение прежних `item`/`local_item` сохранено для совместимости тестовых вызовов.

Регрессионный тест `binder041`: три записи с карточками по 1,1 млн символов,
реальный запуск службы через Binder, Intent меньше 4 KiB, обработка всех трёх
заданий, полное сохранение метаданных и отказ для удалённой записи.
Рабочие загрузки и данные физического телефона тестом не затрагиваются.

Проверки прошли: `assembleRelease`, `assembleReleaseAndroidTest`, `lintRelease`,
`binder041` на эмуляторе MAppTest и проверка прежней подписи APK.
Эмулятор выключен, Gradle-демоны остановлены; оставшихся процессов нет.
