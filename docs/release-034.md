# MApp / MCore 0.3.4

## Карточка и источники

Карточка использует серверный индекс произведений (`works`) и их файлов-источников.
В сериалах порядок: описание → сезон → серия → источник → просмотр / скачивание →
разделитель → скачивание сезона. Последняя просмотренная серия отмечена в списке.
Повторные переключения источников обновляют состояние двух постоянных кнопок.
Неизвестное разрешение обозначено `N\A`, активная загрузка — стрелкой вниз.

Сервер сохраняет манифесты файлов и очередь индексации в SQLite. Получение метаданных
само по себе не запускает загрузку видео. Раздачи сезонов и нескольких сезонов
объединяются по явно указанным S/E; неоднозначные файлы остаются отдельными вариантами.
Для циклов поддержаны явные номера фильма/части. Название вроде «Шерлок Холмс» без
указаний состава недостаточно для автоматического отождествления всех фильмов цикла.

«Скачать сезон» доступно только при подтверждённом числе эпизодов и наличии их всех
в выбранном источнике. Данные о полном составе берутся из однозначного описания
одно-сезонной раздачи или импортированных IMDb-связей. Наличие файлов 1–3 само по себе
не означает, что сезон состоит из трёх серий.

## Локальное воспроизведение

После добавления файла в загрузки кнопка называется «Просмотр». Порог по умолчанию —
10%, настройка «Скачать % для просмотра» (1–100%). Воспроизведение использует только
сохранённые данные; при недоступном диапазоне нет запасного обращения к серверу.
Кнопка остановки оставляет файл и позволяет продолжить его загрузку. Удаление остаётся
отдельным подтверждаемым действием на экране скачанного.

Процент — порог доступа к кнопке, а не гарантия наличия всех необходимых контейнеру
индексов или данных для перемотки. При достижении ещё не скачанного диапазона просмотр
ожидает загрузку или завершается ошибкой чтения; можно возобновить после загрузки данных.

Внешний плеер можно запомнить флажком «Всегда открывать в этом плеере»; выбор сбрасывается
в настройках. VLC получает название отдельным параметром. Для Xvid/DivX автоматически
выбирается программный декодер VLC; доступен ручной выбор режима. Обоснование и результаты
сравнения на телефоне — `decoder-034.md`.

## Изображения и интерфейс

Маленькие, слишком широкие и некорректные постеры отбрасываются. Если подходящего
изображения нет, оно скрыто. Постер в карточке расположен слева с увеличенными отступами.
Главные разделы распределяют доступную высоту. Мультсериалы помечены «Мульт.» после года.
Управление встроенного плеера имеет одинаковые увеличенные размеры и кнопку поворота.

## Внешние метаданные

IMDb: официальный `title.episode.tsv.gz`, привязка исключительно по IMDb ID трекера,
импорт через `python -m mcore.imdb_import /path/title.episode.tsv.gz`. Официальный набор
не содержит постеров. Никакие API-ключи не встраиваются в APK.
Kinopoisk ID учитывается в объединении каталога; отдельный массовый парсер сайта
в этот выпуск не добавлен. Для внешних постеров можно подключить отдельного поставщика
с API (например TMDB, требующий ключ); сейчас используются проверяемые изображения трекеров.

Источники: https://developer.imdb.com/non-commercial-datasets/ и
https://developer.themoviedb.org/docs/getting-started .

## Проверки выпуска

Сервер: 65 тестов пройдены. Android: release/androidTest сборки и lintRelease.
Пройдены проверки карточки и порога 9/10%, независимых позиций серий, очереди сезона,
локального неполного AVI, запоминания внешнего VLC, навигации, восстановления SAF,
отсутствия дубликатов, диагностических логов, SHA-256 блоков, TLS, перемотки и выхода.
Исправлена повторная команда переключения паузы при открытии выбора аудио;
повторная проверка паузы, выбора дорожки, кадров и перемотки пройдена.
Физический телефон использован для диагностики декодера; окончательный APK
передаётся пользователю для самостоятельной установки и повторной проверки.
